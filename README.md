# Better Loading Screen

A Minecraft Forge mod that replaces the world loading screen with a custom one.

一个替换 Minecraft Forge 下世界加载界面的模组

## 功能 / Features

- **自定义加载界面** —— 完全替换原版加载屏幕
- **进度条** —— 底部实时显示加载进度
- **百分比** —— 右下角显示当前进度
- **Minecraft Logo** —— 顶部居中显示

- Custom loading screen with progress bar
- Percentage display
- Show Minecraft Logo
