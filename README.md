# Better Loading Screen

A Minecraft Forge mod that replaces the loading screen with a custom one.

## Features

- Custom loading screen with progress bar
- Percentage display

## Compatibility

- Minecraft 1.20.1
- Forge 47.4.26+

## Installation

1. Install Minecraft Forge 1.20.1
2. Put `betterloadingscreen-x.x.x.jar` into the `mods/` folder
3. Launch the game

## Building
./gradlew build
